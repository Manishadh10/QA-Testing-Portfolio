
# SauceDemo Manual QA Testing Project

## About the Project
This is my first manual software testing portfolio project. I tested the login and logout functionality of the SauceDemo demo e-commerce website.

## Application Under Test
https://www.saucedemo.com/

## Project Objectives
- Verify login with valid credentials.
- Test login with invalid usernames and passwords.
- Validate empty-field error messages.
- Test locked-out user behavior.
- Verify password masking.
- Test login using the Enter key.
- Verify logout and login again.

- Negative Testing
- Input Validation
- Functional Testing
